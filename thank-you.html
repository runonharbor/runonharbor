If you're using your current highlight: .hero-highlight{ background:linear-gradient( transparent 45%, rgba(255,242,120,.85) 45% ); padding:0 4px; font-weight:700; color:#16263D; } and the text wraps to a second line, the highlight may only appear behind parts of the text because inline elements don't always render multi-line backgrounds the way you'd expect. Try this: .hero-highlight{ display:inline; background:linear-gradient( transparent 45%, rgba(255,242,120,.85) 45% ); padding:0 .15em; -webkit-box-decoration-break:clone; box-decoration-break:clone; font-weight:700; color:#16263D; } The key is: -webkit-box-decoration-break: clone; box-decoration-break: clone; This tells the browser to apply the highlight to each wrapped line individually, so the yellow follows the entire sentence even when it breaks across multiple lines. If you want it to look more like a hand-drawn highlighter mark, I'd also tweak it slightly: .hero-highlight{ background:linear-gradient( transparent 38%, rgba(255,242,120,.9) 38% ); padding:0 .2em; -webkit-box-decoration-break:clone; box-decoration-break:clone; } That makes the yellow cover more of the text height and feels more like someone dragged a highlighter across the sentence by hand. I want the top of the text to be covered in highlighter as well If you want the highlight to cover most of the text, not just the bottom 50%, move the transition point much higher. Try: .hero-highlight{ background:linear-gradient( transparent 15%, rgba(255,242,120,.9) 15% ); padding:0 .2em; -webkit-box-decoration-break:clone; box-decoration-break:clone; } Or for an even more aggressive highlighter effect: .hero-highlight{ background:rgba(255,242,120,.9); padding:0 .2em; -webkit-box-decoration-break:clone; box-decoration-break:clone; } That will create a solid yellow highlight behind the entire text, similar to someone running a yellow Sharpie highlighter directly over the words.
